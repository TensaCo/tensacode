# Image prompts for tensorcode.dev

Each image below has a placeholder box on the site that shows this prompt and a
**Copy prompt** button. Generate the image, export it at the listed size, and save it at
the listed path. The page swaps the placeholder for the image automatically the next time
it loads (the `<img>` is already in the page; it is shown as soon as the file exists).

Palette used across the site, for reference: paper `#f7f6f2`, ink `#12151a`,
teal `#3fd1b8` (dark theme) / `#0a7466` (light theme), coral `#ff8e6b` / `#b8482a`.
Images appear in both light and dark themes, so mid-tones work best. WebP at quality
~82 keeps them small; the OG image must be PNG or JPEG.

If you change a prompt here, change the matching `<pre>` in the page too (and the other
way round), so the box and this file never disagree.
